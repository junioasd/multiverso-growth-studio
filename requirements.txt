# NOTA CRÍTICA sobre o Playwright:
# `pip install playwright` instala APENAS a biblioteca Python — os
# BINÁRIOS de navegador (Chromium) são baixados separadamente e NÃO
# estão incluídos neste requirements.txt (são artefatos binários, não
# um pacote pip). Depois de instalar as dependências Python, rode:
#
#     playwright install chromium
#
# (ou `playwright install --with-deps chromium` em uma distribuição
# Linux mínima, para também instalar as bibliotecas de sistema
# operacional que o Chromium headless requer). Sem esse passo,
# `BrowserExecutor` detecta a ausência do binário e retorna
# `UNAVAILABLE` explicitamente — nunca falha de forma obscura, nunca
# finge que a automação de navegador funcionou.
#

# desenvolvido/testado em Python 3.12; em 3.13+, seria necessário
# substituir por um pacote externo equivalente (ex: `audioop-lts`) —
